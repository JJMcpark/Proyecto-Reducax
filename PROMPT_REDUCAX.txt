================================================================================
                    PROMPT PARA CREAR REDUCAX
                    Red Social Educativa con React + TypeScript
================================================================================

Crea una aplicación web completa para una RED SOCIAL EDUCATIVA usando React 18 
con Vite y TypeScript. La aplicación debe conectar estudiantes, docentes e 
instituciones educativas para un aprendizaje colaborativo.

================================================================================
REQUISITOS FUNCIONALES:
================================================================================

AUTENTICACIÓN:
- Login y registro de usuarios
- Roles: Estudiante, Docente, Administrador
- Persistencia de sesión con localStorage
- Credenciales de demo para pruebas

FEED DE PUBLICACIONES:
- Crear publicaciones con contenido y materia/tema
- Sistema de likes (toggle)
- Sistema de comentarios que se guardan
- Botón guardar/bookmark para posts
- Botón actualizar feed
- Posts ordenados cronológicamente (más recientes primero)

PERFIL DE USUARIO:
- Vista de perfil con avatar, bio, institución, carrera
- Estadísticas: seguidores, siguiendo, posts, horas de estudio, grupos
- Pestañas: Publicaciones, Guardados, Acerca de, Ajustes
- Edición de perfil inline
- Compartir perfil (crea post automático)
- Ver posts guardados con opción de quitar

PÁGINA DE POST ÚNICO:
- Vista completa del post desde guardados
- Sección de comentarios expandida
- Botón volver a página anterior
- Ruta: /post/:id

MENSAJERÍA:
- Lista de conversaciones
- Chat en tiempo real (simulado)
- Búsqueda de conversaciones

GRUPOS DE ESTUDIO:
- Lista de grupos disponibles
- Información: nombre, descripción, miembros, materia
- Modal para crear nuevo grupo

INSTITUCIONES:
- Catálogo de instituciones educativas
- Información: nombre, tipo, ubicación, estudiantes, rating
- Filtros por tipo

NAVEGACIÓN:
- Sidebar izquierdo con menú principal
- Navbar superior con:
  - Buscador
  - Iconos de acciones (home, mensajes, grupos)
  - Temporizador Pomodoro integrado (+5/-5 minutos)
  - Logo REDUCAX centrado
  - Toggle modo oscuro/claro
  - Notificaciones con badge
  - Dropdown de usuario con perfil y logout

MODO OSCURO/CLARO:
- Toggle en navbar
- Colores B/N minimalistas
- Transiciones suaves
- Persistencia de preferencia

FOOTER:
- Links de navegación principales
- Sección de recursos (con alerta "En desarrollo")
- Sección legal (con alerta "En desarrollo")
- Copyright

================================================================================
REQUISITOS TÉCNICOS:
================================================================================

STACK:
- React 18 con TypeScript
- Vite 6.x como bundler
- React Router DOM 7 para navegación
- CSS-in-JS (estilos inline con objetos)
- Font Awesome 6.5.1 (CDN) para iconos

ESTADO Y PERSISTENCIA:
- React Context API para estado global (Auth, Theme)
- localStorage para persistencia de:
  - Usuario autenticado
  - Posts y comentarios
  - Mensajes y conversaciones
  - Notificaciones
  - Bookmarks por usuario
  - Preferencia de tema

RUTAS:
- / (Welcome - pública)
- /login (pública)
- /register (pública)
- /feed (privada)
- /profile (privada)
- /messages (privada)
- /groups (privada)
- /institutions (privada)
- /settings (privada)
- /post/:id (privada)
- * (404)
