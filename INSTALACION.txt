DESCRIPCIÓN DEL PROYECTO
------------------------
REDUCAX es una red social educativa desarrollada con React + TypeScript + Vite.
Conecta estudiantes, docentes e instituciones para un aprendizaje colaborativo.

--------------------------------------------------------------------------------
REQUISITOS PREVIOS
--------------------------------------------------------------------------------

1. Node.js versión 18 o superior
   - Descargar desde: https://nodejs.org/
   - Verificar instalación: node --version

2. npm (incluido con Node.js)
   - Verificar instalación: npm --version

3. Git (opcional, para clonar el repositorio)
   - Descargar desde: https://git-scm.com/

--------------------------------------------------------------------------------
INSTALACIÓN PASO A PASO
--------------------------------------------------------------------------------

PASO 1: Obtener el código fuente
--------------------------------
Opción A - Clonar con Git:
   git clone https://github.com/JJMcpark/Proyecto-Reducax.git
   cd Proyecto-Reducax
   git checkout Proyecto

Opción B - Descargar ZIP:
   - Ir a: https://github.com/JJMcpark/Proyecto-Reducax
   - Seleccionar la rama "Proyecto" en el selector de ramas
   - Click en "Code" -> "Download ZIP"
   - Extraer el archivo
   - Abrir terminal en la carpeta extraída

PASO 2: Instalar dependencias
-----------------------------
   npm install

   Esto instalará todas las dependencias necesarias:
   - React 18
   - TypeScript
   - Vite
   - React Router DOM
   - Y otras dependencias del proyecto

PASO 3: Iniciar servidor de desarrollo
--------------------------------------
   npm run dev

   Esto iniciará el servidor en: http://localhost:5173/

PASO 4: Iniciar el servidor de datos (JSON Server)
--------------------------------------------------
   Abrir otra terminal y ejecutar:
   
   npx json-server --watch db.json --port 3001

   Esto iniciará el API mock en: http://localhost:3001/

SOLUCIÓN DE PROBLEMAS COMUNES
--------------------------------------------------------------------------------

1. Error "ENOENT: no such file or directory"
   - Asegúrate de estar en la carpeta correcta del proyecto
   - Ejecuta: npm install

2. Puerto 5173 en uso
   - Cierra otras instancias de Vite
   - O cambia el puerto en vite.config.ts

3. JSON Server no responde
   - Verifica que esté ejecutándose en puerto 3001
   - Comprueba que db.json existe en la raíz

4. Estilos no cargan correctamente
   - Limpia caché del navegador (Ctrl+Shift+R)
   - Verifica que Font Awesome CDN esté accesible
